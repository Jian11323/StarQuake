# 音效路由

真相源：`media/sound/catalog.json`  
实现：`crates/starquake-audio`  
许可：[`media/ATTRIBUTION.md`](../media/ATTRIBUTION.md)（音效一节）

全部音频文件平铺于 `media/sound/` 根目录；`catalog.json` 的 `packs` 仅作逻辑分组。

## 路由

| 路由键 | 包 | 用途 |
|--------|-----|------|
| `jma_eew` | **srev** | JMA 预警发行 / 更新 / 最终 / 取消 / 海啸 |
| `default_eew` | **eewcn** | 非 JMA 预警首报 / 更新 / 危急首报 / S 波抵达 |
| `record` | **eewcn** | 速报提示 |
| `countdown` | **countdown** | 本地 S 波中文倒计时 |
| `ui` | **ui** | 连接与通用通知 |
| `special` | **special** | NHK / EBS 自定义告警 |

## 事件键

| 意图 | 包内键 / 文件 |
|------|----------------|
| JMA 首报 | srev `issue` → `issue.mp3` |
| JMA 更新 | srev `update` → `update.mp3` |
| JMA 最终 | srev `final` → `final.mp3` |
| JMA 取消 | srev `cancel` → `cancel.mp3` |
| JMA 注意/警报附加 | srev `caution` / `warn` |
| 非 JMA 首报（未达危急） | eewcn `issue` → `eewalert.wav` |
| 非 JMA 危急首报 | eewcn `critical` → `eewcritical.wav`（M≥5 **或** 烈度≥7，满足其一） |
| 非 JMA 更新/最终 | eewcn `update`/`final` → `eewupdate.wav` |
| 速报 | eewcn `record` → `newrecord.wav` |
| S 波抵达 | eewcn `arrive_s` → `swavearrive.wav` |

## 预警事件

事件去重键与 UI 一致：`eew_sidebar_group_key(agency)|event_id`（`cinema_event_key`）。
Jian / Wolfx 等同族镜像共用一把钥匙，避免更新报被当成另一路「首报」再播 `eewalert`。
中途接入且报数已 >1（或最终报）：直接播 `update`/`final`，不播 `issue`/`critical`。

| 机构 | 音效包 | 行为 |
|------|--------|------|
| **JMA 族** | SREV | 对齐要石：issue / update / final / cancel，另附 caution / warn |
| **其余机构** | Open EEW CN | 危急判定为 **震级≥M5 或者 烈度≥7**（满足其一，不是且）；仅首报播 `eewcritical`；其后一律 `eewupdate`；未达危急的首报 `eewalert` |

JMA 附加档：

| 条件 | 音效 |
|------|------|
| 取消报 | `cancel` |
| 首报 | `issue` |
| 报数升高且最终报 | `final` |
| 报数升高 | `update` |
| 警报（`is_warn` / 震度≥5弱）且本事件尚未播过 | 附加 `warn` |
| 非警报且震度≥3且尚未播过 | 附加 `caution` |

调查中（`is_assumption` / 震源「調査中」）：仍可播上述事件音，**不**播本地倒计时（对齐要石）。

## 倒计时

仅在本机 `[local]` 经纬有效、且存在活动预警剩余秒时播报：

| 步骤 | 行为 |
|------|------|
| 剩余 > 开始秒 | 不播（默认开始秒为 10，对齐要石 `countdownStart`） |
| 剩余 ≤ 开始秒 | 循环滴答 `countdown.wav`，每一整秒边界重启以对齐 HUD |
| 语音 | `countdown_speech` 开时：≤10 每秒播地牛语音；11–60 仅整十秒 |
| 仅强有感 | 本机预估日本震度 ≥3 或中国烈度 ≥5 才播 |
| 到达 0 | 播 `0s`，停止循环 |

无本机位置时不播报倒计时语音。

## S 波抵达

本机位置有效且倒计时会话算出剩余秒时：剩余首次落到 0（S 波抵达所在地）播 `swavearrive.wav`（与倒计时语音开关无关；启动画面期间不播）。

## 速报

近时窗口内新条目或实质更新时播 Open EEW CN `newrecord.wav`（与 TTS 开关无关；启动画面灌入不播）。

## 海啸

仅 JMA 海啸情报（顶条有效时）。`grade` → SREV 档位：预报=`tsunami1_*`，注意报=`tsunami2_*`，警报/大海啸=`tsunami3_*`。

| 条件 | 音效 |
|------|------|
| 首报（或解除后再发） | `tsunamiN_issue` |
| 同事件更新（换档/改正） | `tsunamiN_update` |
| 解除报 / 顶条被清空 | `tsunamiN_cancel`（N 取解除前档位） |

启动画面灌入的海啸状态不播。预报到期自动清除也会走解除音。

## 台风

活跃列表指纹变化且非首包时播 `ui` 包 `notify`。

## 自定义告警音（可开关）

设置 → 音频 → 音效设置（仅开关，固定内置文件）：

| 开关 | 条件 | 文件 |
|------|------|------|
| NHK 一级新闻铃 | 速报或预警日本震度 ≥6 弱 | `nhk_news_bell.wav` |
| JMA 警报音 | JMA 紧急地震速报由预报升级为警报 | `nhk_eew_alert.wav` |
| 津波警报音 | 津波警报 / 大津波警报 | `ebs_type2_start.wav` |

## 语音播报（TTS）

设置 → 音频 → 语音播报。预警/速报在事件音效之后朗读文案。

| 配置键 | 说明 |
|------|------|
| `tts_enabled` | 总开关（默认关） |
| `tts_engine` | `offline` / `edge` |
| `tts_voice` | 离线音色名（空=系统默认） |
| `tts_edge_voice` | Edge 音色，默认 `zh-CN-XiaoxiaoNeural` |
| `tts_rate` | 语速倍率 0.5–2.0 |

静音或主音量为 0 时不朗读。
