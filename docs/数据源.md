# 数据源

配置：`config/default.toml` → `[sources.*]`  
实现：`crates/starquake-net`

## 总览

| 源 | 协议 | 说明 | 访问令牌 |
|----|------|------|----------|
| **Jian** | WSS `api.sismotide.top` | 未配置令牌则不连接 `/all`；健康态为「异常」 | 设置页 `lk_`→`rt_`；或 `JIAN_REFRESH_TOKEN` / `JIAN_ACCESS_TOKEN`。断线重连前用 `rt_` 换新 `at_` |
| **Wolfx** | WSS + HTTP | `all_eew` 聚合预警/列表；HTTP `cenc_eqlist` 补充 | 无 |
| **P2PQuake** | HTTP | `history?codes=551`，周期 `poll_secs`（默认 1.5s，最低 1s） | 无（请求须带 User-Agent） |
| **FSSN** | WSS | Fan Studio 地震信息；`/fssn`，连接后 `fssnlist` | 无 |
| **Pancakes** | WSS + HTTP | 仅 GQ + JMA-Atom；`/ws/all` 推送 + 冷启动 HTTP | 无 |
| **测站** | WSS / HTTP | `[sources.stations]`：JMA（Jian `/kmoni` 或 NIED 原版）、S-Net、KMA | Jian 中转无需令牌 |
| **台风** | HTTP | `[sources.typhoon]`：活跃台风路径 / 风圈 / 多源预报，约 15s 轮询 | 无 |

### 连接超限说明

IP 白名单 **不等于** 无限并发。公开·径额度·提高（预警/情报约 **6** ·、测站约 **7** ·，以服务端当前配置为准）；长期令牌另有 `max_connections`。  
若同时开着 eewcn / 网页调试 / 多个 StarQuake，仍可能收到 `您·超过服务器连接限制`。关掉多余客·端后再连；本客·端遇此错误会拉长退避，避免狂重连。

上游 JSON 经适配器归一化为 `EewReport` / `EqRecord` 后进入界面快照。

## Jian Project API

| 项 | 内容 |
|----|------|
| 文档 | <https://api.sismotide.top/api/> |
| 默认地址 | `wss://api.sismotide.top/all` |
| 鉴权 | `lk_`（邮件，约 5 分钟）→ `rt_`（约 180 天，写入本机 settings）→ `at_`（约 1 小时，握手用）。每次 `/all` 连接前换新 `at_`；勿写入公开仓库 |
| 开关 | `eew_enabled` / `record_enabled` 分控预警与速报；各预警子源见 `jma_eew` 等 |
| 列表 | 连接后及每约 60s 发送 `cenclist` / `cwalist` / `jmalist` / `hkolist`；全源··合去重后按发震时刻新→旧；预警靠 `/all` 快照与推送 |
| 信封 | `{ type, Data, md5 }`；聚合快照键 `source：*` |

| 上游 type | 归一类型 | 主要字段 |
|-----------|----------|----------|
| `jma-eew` / `cea` / `cea-pr` / `*-eew` | `EewReport` | id、serial、placeName、经纬深震级、originTime(JST ISO)、intensity、isWarn/isFinal/isCancel；`isTraining`丢弃；`isPLUM`→假定；可选 `lgIntensity` |
| `jma-tsunami` | `TsunamiInfo` | `area[]`(name/kind/cleared)、`cancel`/`cleared`/`infoTypeName`、originTime/endTime 毫秒；顶条 + 沿岸描边；优先 Jian |
| `jma` / `cenc` 等速报 | `EqRecord` | telegram/title/infoType/intensity；`infoType=取消`丢弃；`hypocenterUnknown`/`magnitudeUnknown`（及 P2P lat=-200/M=-1）→调查中；JMA `depth=0`/「极浅」→展示「极浅」（不写 `0km`） |

机构展示标签：`cea` → `[CN]`（预警）；`cenc` → `[CENC]`（速报，勿与 CN ··用）；`cea-pr` 按上游 `province` → `[xx地震局]`（如 `[四·地震局]`）。

### 测站（`[sources.stations]`）

| 项 | 内容 |
|----|------|
| JMA | `jma_source`（默认 `jian`）：`jian`（`/kmoni`）／`kmoni`／`lmoni`（NIED `jma_s` GIF） |
| S-Net | `snet_enabled`；`jian` → `/s-net`；`original` → MSIL 切片 + `media/stations/pixels.csv`（MSIL 不可达时自动回退 Jian） |
| KMA | `kma_enabled` → Jian `/kma-station`（`mmi[]` → 中国烈度档展示） |
| 兼容 | 旧键 `jian.station_enabled` 与 `stations.jma_*` 启动时双向对齐 |
| 帧（中转） | 首包 `stations[]`；其后 `int[]` / `mmi[]`，缺测按源约定 |
| 归一 | 計測震度 → JMA 震度；有感写入测站数据与地图点 |
| 鉴权 | 测站中转**无需** `key`；`/all` 仍需 `at_`/`rt_` |
| 帧率 | kmoni / kma / s-net 中转均约 **1s/帧**；S-Net 帧带 `time`（资料时刻）与 `timestamp`（对时），`int[]` 随秒推送 |
| S-Net 对时 | Jian 中转：同 `time`/`int` 只改 `timestamp` 的帧刷新卡片时钟、不改测站数据；原版 MSIL：约 5s 轮询保活时钟，资料仍约每分钟 |
| 僵死重连 | 三条测站看门狗均约 **15s**（勿按「S-Net 分钟一帧」放宽） |

测站数据**不进入** `/all` 聚合；`/all` 与三条测站为**独立长连接**。

## Wolfx

| 项 | 内容 |
|----|------|
| WebSocket | `wss://ws-api.wolfx.jp/all_eew`（可选另加 `cwa_eew`，仅大陆） |
| 连接后查询 | `ping`；预警 `query_jmaeew` / `query_sceew` / `query_fjeew` / `query_cqeew` / `query_cenceew`；列表 `query_cenceqlist` / `query_jmaeqlist` |
| HTTP | `https://api.wolfx.jp/cenc_eqlist.json`（约 45s 轮询，补充台网速报） |
| 文档 | <https://wolfx.jp/apidoc> |
| 上游 type → 归一 | `jma_eew`→预警；`sc_eew`/`fj_eew`/`cq_eew`/`cenc_eew`→预警；`cwa_eew`→预警；`cenc_eqlist`/`jma_eqlist`→速报 |
| agency | `wolfx-jma-eew` / `wolfx-cea` / `wolfx-cea-pr:省` / `wolfx-cwa-eew` / `wolfx-cenc` / `wolfx-jma` |
| CENC 列表字段 | `No1…` 对象；`magnitude` / `latitude` / `longitude` / `depth` / `intensity` 多为**字符串**，须按数字解析 |
| 最终 / 取消 | `isFinal` / `isCancel`，或 `Type` 含「最終」「取消」；**取消报不受 serial 单调约束**（可覆盖更高报数，应对取消电报复用旧 `serialNo`） |

## FSSN

| 项 | 内容 |
|----|------|
| 文档 | <https://fssn-api.fanstudio.tech/#fssn> |
| WebSocket | `wss://fssn-api.fanstudio.tech/fssn` |
| 连接后 | 发送 `fssnlist` 取已有事件；服务端另推 `initial` / `update` |
| 信封 | `{ type, Data, md5 }`；列表为 `fssnlist_response` 的 `Data` 数组 |
| 字段 | `shockTime`（UTC+8）、经纬、`depth`（km）、`magnitude`、`placeName` / `placeName_zh`、`infoTypeName` |
| agency | `fssn`，展示 `[FSSN]`；上游无烈度字段，入库时按震级+深度震中 CSIS 估算（`fill_intensity`） |
| 心跳 | 服务端约 20s `heartbeat`；客户端回 `ping` |

## P2PQuake

| 项 | 内容 |
|----|------|
| HTTP | `history?codes=551&limit=20` 轮询；`poll_secs` 默认 1.5，最低 1 |
| 规范 | <https://www.p2pquake.net/develop/json_api_v2> |
| 解析 | `code=551` → 地震情报（海啸情报改由 Jian `jma-tsunami`）；`depth=0`=极浅（ごく浅い），`-1`=不明 |
| WebSocket | 配置项 `ws_url`（可选） |


## PancakesAPI

| 项 | 内容 |
|----|------|
| 文档 | <https://wiki.aloys23.link/wiki/PancakesAPI> |
| 子源 | 仅 **GQ** + **JMA-Atom**（上游 `jma_volcano`） |
| WebSocket | `wss://…/api/v1/alert/ws/all?clientId=…` |
| 信封 | `{ source, type, action, timestampMs, payload }` |
| GlobalQuake | `source=gq` → 预警列表；`gq_min_magnitude` 过滤（默认开启） |
| JMA-Atom | `source=jma_volcano` → 火山情报列表（默认开启） |

## 合并与健康

| 规则 | 说明 |
|------|------|
| EEW | 同 `(agency, event_id)` 保留更高报数；列表上限 50 |
| Records | 跨 API 按机构族+发震时刻/震中去重；上限 80 |
| 地名 | 融合历史 FE 格网（`media/place/`）；JMA / CWA / HKO / CENC / FSSN 保留原文；HKO：placeName←Region，placeCity←City |
| Station | 每帧有感快照替换；按震度降序，上限 120 |
| 健康文案 | **正常 / 波动 / 异常** |

## 台风

| 项 | 内容 |
|----|------|
| HTTP | `https://api.sismotide.top/get/typhoon.json`（`[sources.typhoon].url`） |
| 周期 | `poll_secs`（默认 15） |
| 开关 | 源 `enabled` + 界面 `show_typhoons` |
| 绘制 | 实况路径（按等级着色）、7/10/12 级风圈、预报线；中心徽章在地图，详情在右上测站卡片下方 |
| 预报源 | `typhoon_forecast_agency`：默认中国；可选全部 / 中国台湾 / 日本 / 美国 / 中国香港 |
| 更新 | 列表指纹变化时播 `ui/notify`，并飞向台风中心（按风圈半径估 zoom，上限 7；首包只跟焦不响；zoom≤3 或用户拖拽锁定时不跟焦） |
