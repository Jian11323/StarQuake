# 自动更新

客户端并行拉取静态清单 `update/manifest.json`；在成功结果中取 **`latest_version` 最新**的一份（同版本优先 Gitee）。镜像优先级固定为：**Gitee → GitHub → 自建服务器**（服务器仅兜底）。更新包按该顺序下载，单地址可重试，并校验 Content-Length 与 SHA256。

## 启动前检查

开启设置项「启动前检查更新」时，在**创建主窗口之前**拉取清单比对版本：

1. 有新版本 → 原生对话框询问是否安装
2. 用户确认且「确认后自动安装」开启 → 进入主界面显示下载进度，校验后应用并退出（安装脚本拉起新版本；E2E 仍可启动前静默）
3. 用户选择暂不更新 → 记录该远程版本，下次启动同版本不再询问（设置里手动「检查更新」仍会询问）
4. 清单拉取失败 → 静默跳过，照常进入主界面

## 应用更新注意

更新通道**互斥**，禁止安装包 / 便携 / Linux 互相回退：

| 当前运行形态 | 下载字段 | 应用方式 |
|----|----|----|
| Windows 安装包版（Program Files、旁路 `Uninstall.exe`、或 `%LocalAppData%\Programs\…`） | 仅 `installer`（setup.exe） | 弹出 NSIS 安装向导；安装完成后拉起（E2E 自动化仍可用 `/S`） |
| Windows 便携版 | 仅 `zip` | 解压后旁路脚本拷贝并重启；**应用阶段不得清空暂存目录** |
| Linux | 仅 `linux` | tar.gz 解压覆盖后重启 |

- 用户在启动询问或主界面点「稍后/否」会记下远程版本，同版本下次启动不再询问。

## 清单地址（并行拉取；优先级 Gitee → GitHub → 服务器）

1. Gitee `master` / `main` raw `update/manifest.json`
2. GitHub `main` / `master` raw `update/manifest.json`
3. 自建服务器（可选兜底；未稳定前客户端可不启用）

## 更新包

清单里的 `installer` / `zip` / `linux` **主 URL 写 Gitee Release**；客户端自动推导 GitHub（及可选服务器）镜像，下载顺序固定为 Gitee → GitHub → 服务器，每地址最多 3 次，校验通过后落盘。

## 字段

| 键 | 说明 |
|----|------|
| `latest_version` | 最新版本号（如 `2.3.3-beta`） |
| `min_supported_version` | 最低仍支持版本（预留） |
| `channel` | 通道名：现为 `beta`（后续一律 Beta，不再发正式 stable） |
| `notes` | 更新日志正文（弹窗展示） |
| `zip` | Windows 便携包 `{ url, sha256 }`（仅便携版使用） |
| `installer` | Windows 安装包 `{ url, sha256, user_interface? }`（仅安装包版使用） |
| `linux` | Linux 包 `{ url, sha256 }`（仅 Linux 使用） |
| `release_notes_url` / `html_url` | 发行说明页 |

## 发版约定

Gitee Release **只保留最新一版**（附件配额有限；发新版前先删旧 Release / 附件）。GitHub 建议保留历史并上传同名附件作后备。

**上传顺序必须：先 Gitee，再 GitHub，自建服务器最后。**

步骤：

1. 打包 Windows 安装包 / 便携包 / Linux 包
2. 删除 Gitee 上旧的 Release（及标签，如需要）
3. **先**在 Gitee 创建新版 Release 并上传三个包 → 改清单 → `python tools/publish_gitee_manifest.py`（写 Gitee `master`+`main`）
4. **再**在 GitHub 创建同名 Release 并上传同名附件；推送代码到 `origin/main`
5. 若有自建服务器镜像，**最后**再同步清单与附件

本机发版用私人令牌写在仓库根 `.gitee_token`（已 gitignore / 打包排除，勿提交、勿打进发行包）。

当前应用版本见根 `Cargo.toml`（现为 **2.3.3-beta**）。后续版本号保持 `2.x.x-beta`，不再发无 `-beta` 后缀的正式版。
